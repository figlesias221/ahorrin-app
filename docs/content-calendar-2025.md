## Checklist por Artículo

Antes de publicar, verificar:

- [ ] **SEO On-Page**
  - [ ] Title optimizado (50-60 caracteres)
  - [ ] Meta description (150-160 caracteres)
  - [ ] H1 con keyword principal
  - [ ] H2/H3 con keywords secundarias
  - [ ] URLs amigables
  - [ ] Keywords density 1-2%

- [ ] **Contenido**
  - [ ] Mínimo 1,500 palabras (según tipo)
  - [ ] Intro enganchadora
  - [ ] Estructura clara con subtítulos
  - [ ] Ejemplos específicos Uruguay
  - [ ] Datos y estadísticas
  - [ ] Conclusión + CTA

- [ ] **Links**
  - [ ] 3-5 internal links
  - [ ] 2-3 external links (autoridad)
  - [ ] Anchor text optimizado

- [ ] **Imágenes**
  - [ ] Featured image optimizada
  - [ ] Alt text en todas las imágenes
  - [ ] WebP format
  - [ ] Tamaño <100KB

- [ ] **Engagement**
  - [ ] CTA claro
  - [ ] Shareable (Twitter, LinkedIn)
  - [ ] Newsletter opt-in

- [ ] **Technical**
  - [ ] Schema markup (ArticlePosting)
  - [ ] Sitemap actualizado
  - [ ] Request indexing en GSC
